# ArtyGal

少年以毕生热忱献身火炮军械，深耕火炮设计、实弹调校、阵地战术，以炮为魂、以火为志，热血逐梦军械之路


# 人物人设
1. 男主·小G
核心执念：一生献身火炮事业，坚信火炮是战场之魂，痴迷弹道学、炮身结构、实弹调校，不善言辞，一谈起火炮滔滔不绝，愿意为打磨一门好炮倾尽心血，护着社团所有人与自己热爱的军械信仰。

2. 女主1 苏凛 - 火炮主设计师
清冷工科才女，精通机械制图与火炮结构设计，和小G理念相合，二人联手改良老式火炮，是男主最默契的技术搭档，外冷内热，默默支持男主所有火炮梦想。

3. 女主2 夏燃 - 前线主炮手
元气热血少女，天生擅长实弹操炮，反应极快，擅长快速架设火炮、应急开火，性格爽朗，是社团冲锋主力，崇拜小G的火炮调校能力。

4. 女主3 温屿 - 弹道观测测算师
细腻冷静，精通气象测算、距离校准、风偏修正，精准报出所有射击参数，是火炮命中目标的核心大脑，心思温柔，默默陪伴男主钻研理论。

5. 女主4 秋柚 - 军械后勤调校师
擅长炮架维护、零件改装、弹药调配、故障抢修，细心体贴，打理社团所有火炮装备，最懂男主熬夜改炮的辛苦。

6. 敌对社团
老牌强校黑岩重工社，崇尚暴力改装、追求火力碾压，轻视传统精密火炮，屡次嘲讽小G“死磕老式火炮没有前途”，成为前期主要劲敌。
